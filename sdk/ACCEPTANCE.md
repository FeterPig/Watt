# 插件验收清单

插件 DLL 放进 `plugins` 并重启 Watt 后，逐项确认：

## 构建与加载

- [ ] 目标框架为 `net48`，AnyCPU（x64 Watt 可加载），未引用 NuGet 外部包；
- [ ] `Watt.exe --plugins out.txt` 中能看到插件 Id，且没有 `load issues`；
- [ ] `<Watt 安装目录>\watt-startup.log` 中没有 `plugin load failed` / `plugin ... failed` 异常；
- [ ] 插件只引用 `Watt.Plugin.Contracts.dll`（以及可选的 `Watt.Plugin.Support.dll`），
      版本与当前安装一致。

## 功能

- [ ] `--selftest out.json` 中出现目标设备，名称/类型/电量正确；
- [ ] 设备充电时充电状态正确（若协议支持）；
- [ ] 断开设备/让设备休眠后，悬浮窗仍保留该设备与最后一次电量（宿主缓存生效）；
- [ ] 重新唤醒设备后，下一次扫描能刷新电量；
- [ ] 拔出接收器/关闭适配器后，连续 3 次扫描内该设备从列表消失；
- [ ] 设备从未被读到过电量时，不凭空出现在列表里。

## 安全与稳定性

- [ ] 只读优先；如必须发查询帧，已限制频率，且不会修改设备配置；
- [ ] 不在插件里持久化 last-known 缓存，不调用宿主内部文件；
- [ ] `ReadAsync` 不抛异常；超时前返回；不阻塞超过 `SuggestedTimeoutMs`；
- [ ] 不与厂商配置软件同时读写同一设备，或已说明冲突；
- [ ] 插件 Id 唯一、稳定；Priority 合理（第三方通常 ≥60，不覆盖内置来源）；
- [ ] 设备 Id 稳定（蓝牙用 MAC；其他传输用厂商固定 Id），重启后不重复出两行。

## 文档

- [ ] 在仓库/交付说明里记录：设备型号、VID:PID、协议来源、写入的帧、已知限制；
- [ ] 提供测试环境（设备固件、Windows 版本）与验证结果。
